# UI Troubleshooting

Run `bin/install-requirements` for production or add `--development` for test tooling. Run `composer check-platform-reqs` to diagnose missing extensions. Start the UI with `bin/serve-ui`. If port 8080 is occupied, run `TXT_TO_SRT_UI_PORT=8081 bin/serve-ui`. Never use `--ignore-platform-reqs`.
