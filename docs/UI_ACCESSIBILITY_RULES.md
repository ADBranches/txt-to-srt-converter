# UI Accessibility Rules

## Standard

Target WCAG 2.2 AA for the editor, preview, status, conversion, batch, and download workflows.

## Requirements

- Use semantic landmarks, headings, labels, buttons, lists, and tables.
- Every control has a persistent programmatic label.
- All workflows operate with a keyboard.
- Focus order follows visual and document order.
- Focus indicators use a high-contrast Noviq Blue treatment.
- Errors are linked to fields and summarized at the top.
- Status changes use polite or assertive live regions as appropriate.
- Color is never the only status indicator.
- Text and essential controls meet AA contrast requirements.
- Touch targets are at least 24 by 24 CSS pixels, with larger primary actions.
- Reduced-motion preferences are respected.
- Core conversion works without JavaScript.
- Editor line numbers are supplementary and not read as lyric content.
