# UI Style Guide

The interface is light-dominant and uses centralized Noviq Labs Ltd tokens. Navy is used for navigation and primary text, Teal for primary actions, Blue for focus and information, Mint for supporting surfaces, and White for the page background.

## Accessibility

Text and controls target WCAG 2.2 AA. Focus is always visible. Status uses text and structure in addition to color. Reduced-motion and forced-colors preferences are supported.

## Responsive breakpoints

- Mobile: up to 480px
- Tablet: 768px
- Laptop: 1024px
- Wide: 1440px and above
