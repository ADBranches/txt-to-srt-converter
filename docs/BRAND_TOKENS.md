# Noviq Labs Ltd Brand Tokens

## Approved palette

- Noviq Navy: `#102337`
- Noviq Teal: `#45BEA6`
- Noviq Blue: `#00AEEF`
- Noviq Mint: `#C4E5DB`
- Noviq White: `#F8FCFE`

## Semantic assignment

- Primary: Noviq Navy
- Secondary: Noviq Teal
- Accent: Noviq Blue
- Supporting surface: Noviq Mint
- Main background: Noviq White

## Usage requirements

- Brand values must be read from `config/brand.php`.
- Application code must not scatter hard-coded brand values.
- White should remain the dominant interface background.
- Navy should be used for primary text and strong surfaces.
- Teal and Blue should be used for actions and highlights.
- Mint should be used for subtle supporting surfaces.
- Terminal colors must have a non-color fallback.
